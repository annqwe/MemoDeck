# 📚 MemoDeck

**MemoDeck** — это Android-приложение для эффективного запоминания информации с помощью флеш-карточек. Оно использует алгоритм интервального повторения SM-2 (как в Anki) и искусственный интеллект (Gemini AI) для генерации вопросов.

## ✨ Основные функции
*   **Умное повторение:** Карточки показываются именно тогда, когда вы начинаете их забывать.
*   **ИИ-генерация:** Встроенный ИИ создает карточки по любой теме за пару секунд.
*   **Режим теста:** Проверка знаний с вариантами ответов (Multiple Choice).
*   **Помодоро-таймер:** Встроенный таймер для продуктивной учебы без перегорания.
*   **Статистика:** Календарь активности и профиль пользователя.
*   **Темная тема:** Современный дизайн с поддержкой двух тем.

## 🛠️ Стек технологий
*   **Язык:** Kotlin
*   **UI:** Jetpack Compose (Material 3)
*   **База данных:** Room (локальное хранение)
*   **Архитектура:** MVVM
*   **ИИ:** Google Gemini API
*   **Настройки:** DataStore

## 🚀 Установка
1. Скачайте APK-файл **`MemoDeck-v1.0.apk`** из корня этого репозитория (или из раздела **Releases**).
2. Установите его на устройство под управлением Android 8.0 (API 26) и выше.

*(Если вы разработчик: откройте проект в Android Studio, дождитесь синхронизации Gradle и нажмите Run).*
